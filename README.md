# BT Gizli Yilbasi Hediyesi

Statik GitHub Pages demosudur.

## Yayinlama
1. Bu dosyalari GitHub repository'nizin kok dizinine yukleyin.
2. Settings > Pages bolumune gidin.
3. Deploy from a branch secin.
4. Branch olarak main, klasor olarak /(root) secin.
5. Save deyin.

## Onemli guvenlik notu
Bu statik surumde sifre istemci tarafindaki JavaScript icindedir ve kaynak kodu inceleyen biri tarafindan gorulebilir. GitHub Pages sunucu tarafli PHP/Node calistirmadigi icin gercek kimlik dogrulama ve merkezi, kalici cekilis verisi saglamaz.

Gercek kurum ici kullanim icin backend ve veritabani kullanin (ornegin Azure Static Web Apps + Azure Functions + Azure SQL/Cosmos DB veya Vercel + Supabase).
